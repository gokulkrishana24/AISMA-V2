# Agent Capabilities (Phase 3)

All agents use the shared `LLMProvider`/Model Manager, are tenant-scoped, scan untrusted inputs, and fail closed on governance errors. Outputs are analysis/drafts unless a verified integration explicitly confirms an external action (none claimed for live publishing/SEO/competitor APIs).

| Agent | ID | Key task types | Outputs (typical) | Guardrails |
|---|---|---|---|---|
| Search Visibility | `search_visibility` | `seo_analysis`, `keyword_research`, `search_visibility`, `content_gap_analysis` | keyword opportunities, search intent, content gaps, topics, optimization recommendations, evidence/confidence/risks | **No invented live rankings/search-volume data**. Marks findings as supplied-data analysis when no real integration exists. |
| Market Radar | `market_radar` | `competitor_analysis`, `market_trend_analysis`, `positioning_analysis` | competitor observations, market signals, strategic opportunities, risks, recommended actions | **Never fabricates competitor campaigns, prices, or promotions**. Missing data marked unknown. |
| Content Engine | `content_engine` | `content_generation`, `caption_generation`, `content_calendar`, `copy_repurpose` | main draft, hooks, CTA, hashtags, SEO keywords, channel variants, verification flags | Brand-OS restrictions/prohibited claims applied when provided. **No invented testimonials/statistics/awards/claims**. Drafts flagged for human review before external use. |
| Creative Studio | `creative_studio` | `creative_brief`, `image_prompt_generation`, `video_storyboard`, `visual_campaign_plan` | creative brief, visual direction, prompts, scripts, scene breakdown, asset requirements, aspect ratios | **Does not claim image/video generation** without real service confirmation. |
| Publishing & Social | `publishing_social` | `prepare_publishing_job`, `validate_post`, `recommend_schedule`, `reconcile_status` | pending job/validation/schedule recommendation, integration status | **Never bypasses approval**; no fabricated publication. Returns `integration_not_configured` when integration absent. Actual publishing requires human approval, permissions, kill-switch clear, policy approval, credentials, approved content state. |
| Reviews & Reputation | `reviews_reputation` | `review_analysis`, `review_response_draft`, `reputation_summary` | classifications, sentiment, complaints, response drafts, escalation flags | **Negative reviews/complaints/sensitive cases require human approval**. No auto-publish replies. |
| Leads & Conversations | `leads_conversations` | `lead_classification`, `conversation_summary`, `follow_up_draft` | intent (`high_intent/support/pricing_inquiry/general_inquiry/complaint/spam/unknown`), score, priority, summary, suggested reply, follow-ups | **No invented pricing/availability/delivery/contract commitments**. Deterministic escalation rules (high intent/complaint/threshold). |
| Results & ROI | `results_roi` | `roi_analysis`, `campaign_performance`, `kpi_summary` | ROI/ROAS/CPL/conversion/CTR calculations, missing-value markers, optional narrative | **All math in Python** from supplied metrics. Missing/undefined values explicit. **No invented revenue/spend/conversion/attribution data**. |
